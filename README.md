# 📚 LibraHub - Library Management System

A modern MERN Stack Library Management System developed to simplify library operations with secure authentication, role-based access control, book management, borrowing system, and detailed reporting.

---

## 🚀 Features

### 🔐 Authentication
- User Registration
- Secure Login
- JWT Authentication
- Role-Based Authorization

### 👨‍💼 Admin
- Dashboard
- Add/Edit/Delete Books
- Upload Book Cover Images
- Manage Students
- Issue Books
- Return Books
- Borrow Records
- Reports & Analytics
- Export Reports to PDF
- Export Reports to Excel

### 👨‍🎓 Student
- Dashboard
- Search Books
- View Book Details
- Borrowed Books
- Return Books
- Profile Management

---

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/mahnoorjabbar719/LibraHub-Library-Management-System.git
```

### Frontend

```bash
cd Frontend/client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run dev
```

## 🔑 Environment Variables

Backend

```
PORT=5000
MONGO_URI=Your MongoDB URI
JWT_SECRET=Your Secret
```

Frontend

```
VITE_API_URL=http://localhost:5000/api
```
