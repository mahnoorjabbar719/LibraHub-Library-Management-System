## 📖 About the Project

**LibraHub** is a modern **Library Management System** built with the **MERN Stack**. It simplifies library operations by providing secure authentication, role-based access control, book management, borrowing and returning functionality, reporting, and a responsive user interface.

The system is designed for **Administrators, Librarians, and Students**, making library management efficient, organized, and user-friendly.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/mahnoorjabbar719/LibraHub-Library-Management-System.git
```

---

## Frontend

```bash
cd Frontend/client

npm install

npm run dev
```

---

## Backend

```bash
cd server
node server.js
npm install

npm run dev
```

---

# 🔑 Environment Variables

## Backend (.env)

```env
PORT=5000

MONGO_URI=YOUR_MONGODB_ATLAS_URI

JWT_SECRET=YOUR_SECRET_KEY

CLOUDINARY_CLOUD_NAME=YOUR_CLOUD_NAME

CLOUDINARY_API_KEY=YOUR_API_KEY

CLOUDINARY_API_SECRET=YOUR_API_SECRET
```

---

## Frontend (.env)

```env
VITE_API_URL=https://YOUR-RENDER-BACKEND.onrender.com/api
```
